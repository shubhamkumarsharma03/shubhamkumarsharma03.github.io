# Contributing to Portfolio

Thank you for your interest in contributing! While this is a personal portfolio, I welcome suggestions and improvements.

## How to Contribute

1.  **Fork the repository** to your own GitHub account.
2.  **Clone the project** to your local machine.
3.  **Create a new branch** for your feature or bug fix:
    ```bash
    git checkout -b featured/your-feature-name
    ```
4.  **Make your changes** and commit them with descriptive messages.
5.  **Push your branch** to your forked repository.
6.  **Open a Pull Request** to the `main` branch of this repository.

## Coding Guidelines

-   **TypeScript**: Ensure clear typing; avoid `any` where possible.
-   **Structure**: Keep components modular and reusable in `src/components`.
-   **Styling**: Use CSS variables for theming (colors, fonts) to maintain consistency.
-   **Linting**: Run `npm run lint` before committing to ensure code quality.

## Reporting Issues

If you find a bug or have a suggestion, please [open an issue](https://github.com/shubhamkumarsharma03/shubhamkumarsharma03.github.io/issues) with details.
